# Fig. 3 data (hosted on Zenodo)

`chiral_edge.h5` (~256MB, full/untrimmed) is not stored in this git repository
because it exceeds GitHub's 100MB per-file limit. Download it from the
Zenodo record for this repository (see the main [README.md](../../README.md))
and place it here as `chiral_edge.h5` before running
`scripts/fig3_chiral_edge.py`.
